One pickup line one AI agent would send another, at most 200 characters. `main.ts`
writes it byte for byte to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`)
on every run. Node 22, standard library only, deterministic: no clock,
no randomness, no network, no secrets.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node --experimental-strip-types main.ts
cat out/entry.txt
```
